Руководство 1CParserPFF

1. Назначение

1CParserPFF анализирует файлы замеров производительности 1С (.pff) и формирует текстовые отчёты для разработчика и LLM.

2. Режимы

  • TRACE — анализ цепочки выполнения («что произошло»).
  • PERF — анализ времени и узких мест («почему медленно»).
TRACE и PERF решают разные задачи. Для выводов о производительности используйте PERF.

3. TRACE v7

Детализация TRACE

  • compact — режим по умолчанию.
  • full — расширенный отчёт.

Значение normal удалено; при передаче через CLI автоматически переводится в compact с предупреждением.

Порядок секций TRACE

  1. === TRACE [FULL|COMPACT] ===
  2. === TRACE META ===
  3. === TRACE COVERAGE ===
  4. === MODULES MAP ===
  5. === EXECUTION FLOW ===
  6. === CALL INDEX ===
  7. === MODULES ===
  8. === TRACE REPRODUCE ===

Соглашения

  • #123 — подтверждённый факт (FACT).
  • ?123 — эвристическая связь (INFERRED).
  • M01:47 — ссылка на модуль и строку (через MODULES MAP).

4. GUI

  • Два режима TRACE: Обзор (compact) и Подробный (full).
  • Поле порога отображается только для PERF.
  • Поля «Точка входа» и «Разворачивать имена модулей» удалены.

5. CLI

python src/pff_parser.py <input.pff> [output.txt] [options]

Основные параметры:

  • --mode {TRACE,PERF}
  • --trace-detail full|compact (только TRACE)
  • --threshold N (только PERF)
  • --no-context
  • --no-model-prompt
  • --no-compact — deprecated alias для --trace-detail full
  • --no-expand-modules — deprecated no-op

6. Имена выходных файлов

Если путь отчёта не указан явно:

  • *_TRACE_COMPACT.txt
  • *_TRACE_FULL.txt
  • *_PERF.txt

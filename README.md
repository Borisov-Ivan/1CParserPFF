# 1CParserPFF

Проект для парсинга и анализа файлов замеров производительности 1С (PFF).

## Структура проекта

- `src/` — Исходный код парсера (Python).
- `docs/` — Документация и спецификации формата PFF.
- `tests/` — Тестовые замеры и скрипты для проверки.
- `tools/` — Вспомогательные утилиты.
- `xml/` — Тестовая конфигурация 1С для генерации эталонных замеров.

## Текущее состояние

Проект находится в стадии активной разработки и реверс-инжиниринга формата PFF.
Цель — создать точный и эффективный парсер, который корректно обрабатывает контекст выполнения (Клиент/Сервер) и предоставляет удобные форматы для анализа (TRACE, PERF) с помощью LLM.

## Запуск

```bash
cd src
python pff_parser_gui.py
```
